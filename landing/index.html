최신 v0.1.12 · 내부 업무용 포터블 배포

핵심

관리대장만 쓰면, 보고 숫자는 맞춰집니다

여러 Excel을 손으로 맞추지 않습니다. 한곳의 원천 데이터에서 현황과 보고서를 집계합니다.

  1. 01

    관리대장 SSOT

    민원 CRUD, HWPX 민원카드 가져오기, 사진 첨부까지 한 화면에서.

  2. 02

    자동 집계 보고

    부서별현황 · 총괄표 · 일일보고 · 대시보드가 동일 기준으로 반영.

  3. 03

    포터블 단독 운영

    Node 설치 없이 USB·공유폴더에서 실행. 데이터는 로컬 SQLite에 보관.

다운로드

플랫폼별 포터블 패키지

ZIP 해제 후 실행 스크립트로 시작합니다. 앱 데이터는 패키지 폴더의 data에 저장됩니다.

  • Windows 64비트 · x64
  • Linux 64비트 · x64
  • macOS Apple Silicon · arm64
  • macOS Intel · x64

변경 이력

릴리스 노트

시작

압축 풀고, 실행하고, 브라우저로

OS별 실행 파일은 패키지 안 안내(사용방법.txt 등)를 따릅니다.

  1. ZIP 해제 원하는 폴더에 압축을 풉니다.
  2. 서버 실행 압축을 푼 폴더에서 Windows는 my-minwon-server.bat을, macOS·Linux는 my-minwon-server.sh을 실행합니다.
  3. 로그인 열린 브라우저에서 관리자 계정으로 접속합니다. 초기 계정은 패키지 안내 파일을 참고하세요.
