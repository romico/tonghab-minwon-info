# 사내망 모바일·현장 확장 — 요구사항

> 상위: [README.md](./README.md) · 상태: 기획 초안 · 본제품 PRD와 분리

## 1. 목표

사내망에서 담당자가 **모바일로 민원 원천(HWPX·카메라)을 넣고**, 현장 **처리 즉시 처리전/후 사진을 올리며**(오프라인 시 동기화), 집계 Excel을 **이메일로 보내는** 것.

## 2. 비목표 (본 트랙에서도 당장 안 함)

- 앱스토어 공개 배포 (사내 MDM/내부 배포 전제)
- 클라우드 멀티테넌시·인터넷 공개 API
- 폰에 Node/SQLite 포터블 이식
- 본제품 Windows 포터블 UX 대체

## 3. 사용자·과업

| 역할 | 과업 |
|---|---|
| 현장 담당 | HWPX 등록, 민원 선택, 처리전/후 촬영·업로드, 동기화 확인 |
| 보고 담당 | 기간·보고일 기준 집계 Excel을 메일로 발송 |
| 운영 | 사내망 서버 기동, SMTP·수신자 화이트리스트, 백업 |

## 4. 기능 요구

### 4.1 입력

| ID | 요구 | 비고 |
|---|---|---|
| MI-IN-01 | `.hwpx` 선택 → 파싱 → 초안 검수 → 등록 | 본제품 HWPX 정책 준수(원본 미보관, JPEG 압축) |
| MI-IN-02 | 카메라로 현장 사진 촬영 후 민원에 첨부 | role `receipt` 기본 |
| MI-IN-03 | 촬영본 저장 전 JPEG 압축 | 본제품 압축 기준 이상(용량) |

### 4.2 처리 즉시 촬영

| ID | 요구 | 비고 |
|---|---|---|
| MI-PROC-01 | 민원 상세에서 **처리전 촬영** | role `before` |
| MI-PROC-02 | 민원 상세에서 **처리후 촬영** | role `after` |
| MI-PROC-03 | 촬영과 함께 처리상태·처리일시 갱신 가능 | 본제품 상태 모델 재사용 |
| MI-PROC-04 | (선택) 완료 전 처리전·후 사진 필수 | 정책 플래그 |

### 4.3 동기화

| ID | 요구 | 비고 |
|---|---|---|
| MI-SYNC-01 | 사내망 연결 시 촬영·상태 변경 **즉시 업로드** | 기본 경로 |
| MI-SYNC-02 | 오프라인 시 로컬 **pending 큐**에 적재 | 기기 저장, 전송 후 삭제 |
| MI-SYNC-03 | 대기/실패/재시도 UI | 건수·오류 메시지 |
| MI-SYNC-04 | 충돌 정책 명시 | 권장: 사진은 append, 메타는 서버 version/시각 기준 |

큐 항목 최소 필드: `localId`, `complaintId`, `photo`(role+blob), `status?`, `createdAt`, `retryCount`.

### 4.4 집계 Excel 메일

| ID | 요구 | 비고 |
|---|---|---|
| MI-MAIL-01 | 서버에서 집계 Excel 생성 | 본제품 `src/export/*` 로직 재사용 |
| MI-MAIL-02 | 사내 SMTP로 발송 | 수신자 화이트리스트 |
| MI-MAIL-03 | 마스킹 옵션·감사 로그 | 개인정보 정책 준수 |
| MI-MAIL-04 | (대안) 서버 생성 파일을 공유시트/첨부용으로 전달 | SMTP 불가 환경 |

### 4.5 사내망·보안

| ID | 요구 | 비고 |
|---|---|---|
| MI-SEC-01 | 서버 바인딩을 사내 인터페이스로 | `127.0.0.1` 전용 금지 |
| MI-SEC-02 | 세션·HTTPS 또는 VPN | 사진·개인정보 포함 |
| MI-SEC-03 | 동기화 큐는 전송 성공 후 삭제 | 기기 잠금 전제 |

## 5. 우선순위 (제안)

| 단계 | 범위 | 산출 |
|---|---|---|
| P0 | 사내망 서버 접속 + 민원 조회/상태 + 카메라 `before`/`after` 즉시 업로드 | 현장 처리 MVP |
| P1 | 오프라인 동기화 큐 | 현장망 단절 대응 |
| P2 | HWPX 모바일 반입 | PC와 동등 입력 |
| P3 | Excel 이메일 발송 | 보고 자동화 |

## 6. 성공 기준 (초안)

- 현장 담당이 민원 1건을 열어 처리전·후 사진을 **1분 이내** 서버에 반영(온라인)할 수 있다.
- 오프라인에서 촬영한 건이 복귀 후 **누락 없이** 동기화된다.
- 보고 담당이 앱/웹에서 수신자를 지정해 **동일 집계 Excel**을 메일로 받을 수 있다.
- 본제품 포터블 배포·단일 PC 운영 경로는 **변경 없이** 유지된다.
